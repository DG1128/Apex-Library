## 🐛 3. Reporting Bugs

If you have confirmed a reproducible bug in Apex LMS:

1. Search existing [GitHub Issues](https://github.com/DG1128/Apex-Library/issues) to ensure it has not already been reported.
2. Open a new issue using the **[Bug Report Template](https://github.com/DG1128/Apex-Library/issues/new?template=bug_report.yml)**.
3. Provide your Node.js version, operating system, and the error logs.
