## 🎬 Tips for Capturing High-Quality Screenshots

1. **Browser Zoom**: Set browser zoom to 100% in Chrome or Edge.
2. **Theme**: Capture screenshots in both Dark Mode and Light Mode for maximum visual appeal.
3. **Demo Data**: Run `npm run seed` first to ensure full, realistic sample datasets appear in all tables and charts.
4. **Tool Recommendation**:
   - Windows: Use `Win + Shift + S` or the Windows Snipping Tool.
   - Screen to GIF: Use [ScreenToGif](https://www.screentogif.com/) (free & open source) to record the `demo.gif`.
